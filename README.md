# Clajent

A Clojure project demonstrating Python interoperability with LLM integration.

## Quick Start

```bash
# 1. Run setup script
./setup.sh

# 2. Set API key
export OPEN_ROUTER_KEY='sk-or-v1-your-key-here'

# 3. Add to shell config (optional, for persistence)
echo 'export OPEN_ROUTER_KEY="your-key-here"' >> ~/.bashrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

## What the Setup Script Does

The `setup.sh` script automatically installs and configures:

- **Leiningen** - Clojure build tool and dependency manager
- **Babashka** - Fast-starting Clojure scripting environment
- **clj-nrepl-eval** - Tool for evaluating Clojure code via nREPL
- **Python virtual environment** - Isolated Python environment in `./venv`
- **Python dependencies** - numpy, pandas, scipy, matplotlib, openai, mcp, pydantic
- **Clojure dependencies** - All project dependencies from `project.clj`
- **python.edn** - Configured with correct venv path

## Prerequisites

The setup script will check for these required system dependencies:

- **Java** 11 or higher ([Download](https://adoptium.net/))
- **Python** 3.8 or higher ([Download](https://www.python.org/downloads/))
- **curl** - for downloading tools

## Usage

### Running Clojure Code

```bash
# Start interactive REPL
lein repl

# Run main function
lein run -m clajent.core/go

# Quick evaluation with Babashka
bb -e "(+ 1 2 3)"
```

### Using clj-nrepl-eval

The `clj-nrepl-eval` tool allows you to evaluate Clojure code against a running nREPL server:

```bash
# Discover running nREPL servers
clj-nrepl-eval --discover-ports

# Start a REPL in one terminal
lein repl

# In another terminal, evaluate code
clj-nrepl-eval -p 7888 "(+ 1 2 3)"

# Evaluate with timeout
clj-nrepl-eval -p 7888 --timeout 5000 "(Thread/sleep 1000) (println \"Done!\")"

# Show help
clj-nrepl-eval --help
```

### Running Python Code

```bash
# Activate virtual environment
source venv/bin/activate

# Run Python scripts
python timeseries/timesense/basic_usage.py

# Run MCP server
python timeseries/timesense/ts_server.py

# Deactivate when done
deactivate
```

### Testing Python-Clojure Interop

```bash
# In Clojure REPL
(require '[clajent.python-interop :as py-interop])

# Python interop uses libpython-clj to call Python from Clojure
# The setup script configures python.edn with the correct venv path
```

## Configuration Files

### `python.edn`

Auto-generated by `setup.sh` to configure libpython-clj:

```clojure
{:python-executable "./venv/bin/python"
 :python-verbose true}
```

**Note:** This file uses a relative path to your project's venv, making it portable across different systems and locations.

## Troubleshooting

### "Command not found: lein" or "Command not found: bb"

Ensure `~/.local/bin` is in your PATH:

```bash
export PATH="$HOME/.local/bin:$PATH"

# Make permanent
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### "ModuleNotFoundError" in Python

Activate the virtual environment:

```bash
source venv/bin/activate
```

### "Failed to find python executable"

Re-run the setup script to regenerate `python.edn`:

```bash
./setup.sh
```

### "OPEN_ROUTER_KEY environment variable is not set"

Set the environment variable:

```bash
export OPEN_ROUTER_KEY='your-api-key-here'
```

### clj-nrepl-eval connection issues

Ensure an nREPL server is running:

```bash
# Terminal 1
lein repl

# Terminal 2 - discover ports
clj-nrepl-eval --discover-ports

# Use the discovered port
clj-nrepl-eval -p <port> "(+ 1 2 3)"
```

## Development

### Starting Development

```bash
# Start REPL for interactive development
lein repl

# In REPL
user=> (require '[clajent.core :as core] :reload)
user=> (core/go)
```

### Testing Changes

```bash
# Reload namespace after changes
(require '[clajent.core :as core] :reload)

# Use clj-nrepl-eval for testing specific functions
clj-nrepl-eval -p 7888 "(require '[clajent.core :as c] :reload)"
clj-nrepl-eval -p 7888 "(c/some-function)"
```
